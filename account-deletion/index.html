Account Deletion

読者アカウントを
削除する

DUSTLINE公式アプリ（開発者：ponsan／運営：DUST LINE）の読者アカウントと、 サーバーに保存された関連データを完全に削除できます。

アプリ内で削除 Webから依頼 削除される情報 保持される情報

01 / IN APP

アプリ内で完全削除する

  1. DUSTLINE公式アプリを開き、「マイページ」を選びます。
  2. 削除する読者アカウントでログインします。
  3. 「アカウントを削除」を選びます。
  4. 表示内容を確認し、「完全に削除する」を選びます。

処理が完了するとログアウトされ、同じアカウントへ戻すことはできません。

02 / WEB REQUEST

アプリを利用できない場合

登録したメールアドレスから、件名「DUSTLINE公式アプリ アカウント削除依頼」で support@dustline.jp へご連絡ください。本人確認後、原則7日以内に削除し、完了を返信します。

削除をメールで依頼する

03 / DELETED DATA

削除される情報

  • 読者アカウントの利用者ID
  • 登録メールアドレスと認証情報
  • 当該アカウントに紐づく読者情報

端末に保存したアプリデータは、アプリのデータ消去またはアンインストールで削除できます。

04 / RETENTION

削除後に保持される情報

法令上の保存義務または不正利用防止に必要な情報がない限り、読者アカウント情報は保持しません。 削除依頼に関するサポートメールは、対応記録として最長1年間保持した後に削除します。
