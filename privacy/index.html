02 / SCOPE

適用範囲

本ポリシーは、DUSTLINEアプリ開発事業部がGoogle PlayおよびApp Store等で提供するアプリと、 apps.dustline.jp に適用されます。 個別アプリの画面やストア掲載情報に追加の説明がある場合は、その説明も本ポリシーの一部となります。

当事業部のアプリは、原則として利用者が入力したデータを端末内に保存する 「ローカルファースト」の設計です。アプリごとの実装とストアのデータセーフティ申告を一致させます。

03 / DATA HANDLING

取扱う情報と利用目的

DUSTLINE公式アプリの読者アカウント

DUSTLINE公式アプリで読者登録またはログインを選択した場合、メールアドレス、 認証サービスが発行する利用者ID、認証日時を、本人確認、ログイン状態の維持、 読者サポートのためにSupabase上で処理します。読者登録をしなくても創刊号は閲覧できます。 本アプリは広告識別子、位置情報、連絡先を取得しません。

利用者がアプリ内で作成する情報

記録、学習状況、メモ、設定、利用者が選択した写真など、各アプリの機能に必要な情報を扱う場合があります。 これらは原則として端末内に保存され、当事業部が運営するサーバーへ自動送信しません。

端末機能と権限

写真、通知、ファイル保存等の権限は、該当機能を利用者が選択したときに必要な範囲で使用します。 権限を許可しない場合でも、権限を必要としない機能は利用できます。

購入に関する情報

有料機能があるアプリでは、Google PlayまたはAppleが決済を処理します。 当事業部は購入状態や取引識別子を確認する場合がありますが、クレジットカード番号等の決済情報は取得しません。

広告・利用状況・障害情報

広告、アクセス解析またはクラッシュ解析を使用するアプリでは、 端末情報、アプリの利用状況、広告識別子、IPアドレス、広告への反応等がサービス提供者へ送信される場合があります。 使用の有無と対象データは、各アプリのストア掲載情報およびアプリ内で明示します。

サポートへのお問い合わせ

利用者から連絡を受けた場合、メールアドレス、アプリ名、端末・OS・アプリのバージョン、 問い合わせ内容、任意で添付された画像やファイルを、返信と問題調査のために利用します。

本Webサイトの技術情報

本サイトの配信事業者により、アクセス日時、閲覧ページ、ブラウザ・端末情報、 IPアドレス等の標準的なログが、配信、安全確保、不正利用防止のために処理される場合があります。

04 / SHARING

第三者への提供・外部サービス

当事業部は、利用者の個人情報やアプリ内データを販売しません。

  • 利用者が共有・書き出し機能を操作し、他のアプリやサービスへ送信する場合
  • Google PlayまたはAppleによるアプリ配信、決済、購入状態の確認に必要な場合
  • 広告・解析・障害解析を採用するアプリで、明示したサービス提供者が必要なデータを処理する場合
  • 法令に基づく開示要請への対応、人命・財産の保護、不正利用防止のために必要な場合

Googleのサービスを利用するアプリにおけるデータの取扱いは、 Google プライバシーポリシー もご確認ください。

05 / SECURITY

安全管理

当事業部は、取扱う情報の種類とリスクに応じて、OSのアプリ領域への保存、 必要最小限の権限、通信時の暗号化、アクセス制限等の合理的な安全管理措置を講じます。 ただし、インターネット通信や端末上の保存について、完全な安全性を保証するものではありません。

06 / RETENTION & DELETION

保存期間と削除

  • 端末内のデータは、利用者がアプリ内で削除するか、アプリをアンインストールするまで保存されます。
  • 利用者が書き出したファイルや端末バックアップは、利用者自身で管理・削除してください。
  • サポート情報は、対応、品質改善および法令上必要な期間に限って保存し、目的達成後に削除または匿名化します。
  • 外部サービスが処理する情報は、各サービス提供者の保存・削除方針に従います。

アプリ内にアカウント作成機能がない場合、当事業部側に削除対象となるアカウントはありません。 サポート問い合わせ情報の削除を希望する場合は、 support@dustline.jp へご連絡ください。

DUSTLINE公式アプリの読者アカウントは、アプリの「マイページ」から本人が完全削除できます。 アプリを利用できない場合は、 アカウント削除案内 から削除を依頼できます。

07 / CHILDREN

子どもの利用

当事業部の一般向けアプリは、13歳未満の子どもを主な対象としていません。 子ども向けとして提供するアプリがある場合は、対象年齢と適用法令に応じた追加の取扱いを明示します。

08 / CHANGES

本ポリシーの変更

アプリの機能、利用するサービス、法令等の変更に応じて本ポリシーを改定することがあります。 重要な変更は、本ページまたは該当アプリ内でお知らせします。
